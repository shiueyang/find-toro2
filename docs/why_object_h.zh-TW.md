# 為什麼認為 OBJECT H（NORAD 66673，2025-276H）就是 TORO-2

整理日期：2026-09-15。證據分四層，前兩層來自外部目錄，後兩層是本專案用與名字無關的物理量獨立算出來的。

## 1. 部署時序與第三方識別

- SpaceX Transporter-15 的部署序列從 TORO-2 開始（Spaceflight Now：「deployment began with the Toro2 spacecraft a little more than 54 minutes after liftoff」）。GCAT 記錄的分離時刻是 2025-11-28 19:39:09 UTC，是 140 個酬載中第一顆。
- Jonathan McDowell 的 GCAT 依部署時序與早期軌道資料，把 2025-276H 指派為 TORO2（TASA/PYRAS）。這是目前唯一對這批未識別物件做過系統性指派的公開來源；satellitemap.space 等網站顯示的「TORO2 = 66673」都是轉抄自 GCAT。
- 限制：GCAT 自己把這個指派標為 `?`（推定）。我們用 Space-Track 歷史根數嘗試重現，但公開根數從部署後第 20 天才開始，差異漂移已把部署順序洗掉（Spearman ρ ≈ 0.3，殘差 σ 與整段部署序列的訊號同量級），所以這一層只能算「與 H 相容」，不能算獨立確認。

## 2. 物理等級的排除法

- Celestrak 上 2025-276 目前有 11 個未識別物件。依 GCAT 的指派，屬於 8U/16U 級（10–25 kg、長度 ≥ 0.35 m）的只有 H（TORO2）與 R / DM / CN（CTC-1B / 1A / 1C，16U，21 kg）；其餘是 1U、3U、6U。
- 限制：未識別物件的 GCAT 質量是「跟著指派的名字來的」，不是量測值，所以這一層對 H 和 R 的鑑別力有限，只能排除明顯不同等級的物件。

## 3. 阻力行為（B* 與衰減率）— 與名字無關

- 目前 H 的高度約 490 km，同級受控 8U（BRO-17/20、Black Kite-1、T.MicroSat-1）仍在 500–511 km。H 的 B* 是同級中位數的 2.5–3 倍。
- Space-Track 歷史根數（2025-12-19 ~ 2026-01-08）的半長軸衰減率：H −0.122 km/day，受控 8U 中位數 −0.046 km/day，約 2.6 倍。
- 11 個未識別物件中只有 H 和 R 呈現這種「同級卻掉得快兩倍以上」的行為。一顆入軌後從未建立姿態、帆板展開後翻滾的衛星，正該如此。DM / CN 的衰減率和受控衛星一樣，若它們是 TORO-2，就得假設 TORO-2 其實有在控制姿態，與 beacon 從未開機互相矛盾。

## 4. 面積質量比與 Pyras 實際規格的定量比對 — 最強的一項

- Pyras 提供：質量約 11 kg、帆板已展開、帆板面 8U + 8U + 4U。翻滾狀態的理論 A/m = (本體表面積 0.28 + 帆板雙面 0.40) / 4 / 11 kg = **0.0155 m²/kg**。
- 用衰減率加 NRLMSISE-00 大氣模型（沿軌道取樣 48 點平均密度、當日 F10.7/Ap、Cd = 2.2、Theil–Sen 斜率、剔除交叉標記壞根數）反推：

| 物件 | 反推 A/m (m²/kg) | ÷ 理論值 0.0155 | 對應的 TORO-2 狀態 |
|--|--|--|--|
| **OBJECT H** | **0.021** | **1.36** | 帆板展開且翻滾（模型 ±30% 誤差內） |
| OBJECT R | 0.024 | 1.56 | 同上，但 GCAT 認為是 21 kg 的 16U |
| OBJECT DM / CN | 0.008 / 0.007 | 0.5 | 只能對應「受控」或「帆板未展」 |
| 受控 8U 對照組 | 0.006 – 0.009 | — | 校準用 |
| 3U Dove 對照組 | 0.0094 – 0.0098 | — | 與理論翻滾值 ~0.011 相近，證明絕對尺度可信 |

- 意義：如果 H 是一顆受控的 8U，A/m 應在 0.006–0.009；如果是帆板未展的翻滾 8U，約 0.0064。觀測到的 0.021 只有「帆板展開、翻滾、約 11 kg」能解釋——正是 Pyras 對 TORO-2 現況的描述。這一項完全不依賴 GCAT 的名字或質量。

## 5. 自洽性

四層證據指向同一個結論，而且彼此獨立：第 1 層是部署時序，第 3、4 層是軌道動力學，用的資料與方法不同。唯一同樣通過第 3、4 層的替代者是 OBJECT R，但 R 沒有第 1 層的支持（GCAT 把它給了 CTC-1B，分離時刻晚 4.5 分鐘），且若 R 是 21 kg 的 16U，0.024 的 A/m 需要更大的帆板全展。

## 6. 仍然存在的不確定性

- 本體外形假設為 1×2×4U；若是 2×2×2U，理論值變為 0.0146，結論不變。
- 大氣模型在太陽極大期 500 km 的絕對誤差約 ±30%，Cd 取 2.2 也有 ±15% 的範圍；因此 ×1.36 屬於「一致」，不是「精確吻合」。
- 若 R 也是一顆失聯的衛星（CTC-1B 的狀態我們不知道），單靠軌道動力學無法在 H 與 R 之間做最終裁決；最終確認要靠地面站在 H 的過境時段收到訊號。

## 7. 建議的追蹤順序

1. OBJECT H / 66673（本文件的結論）
2. OBJECT R / 66681
3. OBJECT AB / 66691、OBJECT CZ / 66761
4. OBJECT DM / 66773、OBJECT CN / 66750
